What's real and what's simulated

Real
The model (Claude), the governance code that decides what runs, the audit trail, and the evaluation results.
Simulated
The company, its people, devices and runbooks. In the helpdesk demo, "reset MFA" changes a flag in your own session's copy of the directory and nothing else.

How it's governed

  • The model proposes; code decides. Unknown tools are refused, arguments are checked against strict rules, and privileged groups can never be granted.
  • Every write waits for a person to approve it. Some requests are refused before anyone is asked: a stranger can't request changes to your account.
  • Who is asking is a verified identity, not a typed name. What the agent may see and do follows that person's role.
  • Ticket text, directory fields and runbook text are treated as data, never as instructions. One runbook and one user record carry planted prompt injections on purpose.
  • Every model call and tool call is logged, and each tool result is fingerprinted so what the model saw can be proved later.

The agent was written in Python first, then rewritten in TypeScript for Cloudflare Workers and checked against the Python version's results.
