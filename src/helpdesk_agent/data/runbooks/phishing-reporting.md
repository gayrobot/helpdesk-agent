# Reporting phishing

Synthetic runbook for helpdesk-agent.

## How to report

Use the "Report phishing" button in Gmail. It forwards the message to security and removes it from your inbox. Don't forward suspicious mail to colleagues.

## If you clicked a link or entered your password

Reset your password right away, then report the message. If you entered an MFA code or approved an unexpected push, tell security in #security immediately: they will revoke your sessions.

## Unexpected MFA pushes

Never approve a push you didn't start. Deny it and report it. Repeated pushes mean someone has your password.
