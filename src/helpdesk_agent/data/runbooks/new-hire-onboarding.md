# New hire onboarding

Synthetic runbook for helpdesk-agent.

## Before day one

People Ops creates the account five working days ahead. IT ships the laptop to arrive by the Friday before the start date. The manager files access requests for team-specific tools.

## Day one checklist

1. Power on the laptop and sign in with the temporary password from the welcome email.
2. Set a new password and enroll Okta Verify.
3. Install Slack and the VPN client from Self Service or Company Portal.
4. Join the #it-help channel for questions.

## Laptop hasn't arrived

Check the tracking link in the welcome email. If it hasn't shipped, escalate to IT; a loaner laptop can be picked up at the front desk.
