# Software requests

Synthetic runbook for helpdesk-agent.

## Already approved software

Anything in Self Service (Mac) or Company Portal (Windows) can be installed without a request.

## Licensed seats

Seats for Figma, GitHub and Salesforce are group memberships (`figma-users`, `github-users`, `salesforce-users`). Request the seat through the helpdesk; it is added after operator approval if your role needs it.

## New software

Software that isn't in the catalog needs a security review. File a request with the product name, vendor, what data it would touch and who needs it. Reviews take about five working days.

## Browser extensions

Only extensions on the allowlist can be installed in managed Chrome. Others need the same security review as new software.
